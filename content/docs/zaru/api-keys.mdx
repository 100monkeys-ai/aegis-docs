# API Keys

API keys provide programmatic access to the AEGIS platform. Generate them from
**Settings → API Keys** in the Zaru client.

Above the list of keys the page says: "A key reaches only the connections in the profile you
choose for it; with no profile it reaches none. Every change it asks for waits for your answer
under Approvals." with a link to Approvals. What a key reaches is on
[MCP Tools](/docs/zaru/mcp-tools#connections-and-profiles), and which calls wait for your answer is
the list under "Which calls wait" there.

---

## Creating an API Key

1. Navigate to **Settings → API Keys**.
2. Click **New API Key**.
3. Enter a name for the key (e.g., "CI pipeline", "local development").
4. Select a scope preset or configure custom scopes.
5. Choose the key's profile, or **None** (the default).
6. Choose an expiry period.
7. Click **Create**.

The key value is shown once. Copy it immediately — it cannot be retrieved again.

---

## A Key's Profile

A key reaches only the connections its [profile](/docs/zaru/profiles) names: a key with no
profile reaches none of your connections, whatever you have connected. Each key's row shows its
profile in a selector, **None** first and then your profiles by name, beside a link to the
Profiles page; choosing one sets it at once. The **New API Key** dialog has the same selector,
**None** by default.

While an active key has no profile, the page says "Since 2026-10-16, a key with no profile
reaches none of your connections; choose one below."

---

## Scope Presets

Scope presets provide common permission sets:

| Preset | Permissions |
|---|---|
| **Read-Only** | List and read agents, workflows, executions, and volumes. No mutations. |
| **Execution** | Read-only permissions plus the ability to execute agents and workflows. |
| **Developer** | Execution permissions plus the ability to create and update agents, workflows, and volumes. |
| **Full Access** | All permissions available to your tier, including credential management and team operations. |

### Custom Scopes

Select **Custom** to pick individual scopes from the full list. This is useful when you need
a key with a narrow permission set — for example, a key that can only execute a specific
workflow.

---

## Expiry Options

| Option | Duration |
|---|---|
| 7 days | Short-lived, suitable for temporary scripts |
| 30 days | Standard for development use |
| 90 days | Extended for CI/CD pipelines |
| 1 year | Long-lived, suitable for stable integrations |
| No expiry | The key remains valid until manually revoked |

Expired keys stop working immediately. You can create a new key at any time.

---

## Using API Keys with the MCP Server

Pass the API key as a Bearer token when connecting to the Zaru MCP server:

```text
Authorization: Bearer <your-api-key>
```

See [Connect Zaru to Any MCP Client](/docs/zaru/mcp-client-setup) for client-specific
configuration instructions.

---

## Using API Keys with the SDKs

The Python and TypeScript SDKs accept an API key for authentication:

```python
from aegis import AegisClient

client = AegisClient(api_key="your-api-key")
```

```typescript
import { AegisClient } from "@100monkeys-ai/aegis-sdk";

const client = new AegisClient({ apiKey: "your-api-key" });
```

---

## Revoking Keys

Open **Settings → API Keys**, find the key in the list, and click **Revoke**. The key stops
working immediately. Revocation is permanent — if you need access again, create a new key.

Active sessions authenticated with a revoked key are terminated. Revoking a key also ends any [operator escalation](/docs/zaru/mcp-tools#operator-escalation) it holds.

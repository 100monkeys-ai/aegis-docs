# Beta Invites

During the beta period, access to Zaru is managed through an invite system. Every user
receives a set of invite codes they can share with others.

---

## Sending Invites

Open the invite panel from the sidebar and click **Send Invite**. Enter the recipient's email
address and Zaru sends them an invite code with instructions to sign up.

---

## Invite Codes

Each invite is backed by a unique code. The recipient uses this code during signup to unlock
their account. Invite codes are single-use — once redeemed, the code cannot be used again.

---

## Redeeming an Invite

When you receive an invite code, visit [ask.myzaru.com](https://ask.myzaru.com) and enter
the code during the signup flow. Your account is activated immediately upon redemption.

---

## Chain Invites

When a new user redeems an invite code, they receive their own set of invite codes. This
chain mechanism allows the user base to grow organically during the beta. The number of
codes each new user receives is configured by the platform.

---

## Managing Sent Invites

The invite panel shows all invites you have sent, along with their status:

- **Pending** — the recipient has not yet redeemed the code.
- **Accepted** — the recipient has signed up and activated their account.
- **Expired** — the code was not redeemed before the expiration window.

For pending invites, you can:

- **Remind** — resend the invitation email to the recipient.
- **Dismiss** — remove the invite from your list. The code is invalidated and can no longer
  be redeemed.
